# punto_y_fama
Punto y Fama - a retro 4-digit code cracking game

## Play online with a friend

1. Open the game and click **SHARE CHALLENGE**.
2. Send the generated link to your friend (the challenge code is encoded in the URL).
3. Your friend opens the link and plays your exact 4-digit challenge.
4. To return to random single-player mode, click **SOLO**.
